Asset Count shows which downloadable assets people actually use. Send visitors through a tracked asset URL, keep the original file delivery intact, and bring the resulting totals back into Craft.

Generate a tracked URL for any Craft asset and use it wherever you offer a download. Each visit is counted before the visitor is redirected to the original file, so your templates stay in control of the surrounding experience.

## Features

- **Tracked asset links:** Wrap an existing asset in a countable URL without moving or duplicating the file.
- **Visible totals:** Show download counts in Craft or retrieve them in Twig alongside the asset.
- **Bot filtering:** Keep likely crawlers from inflating totals when bot detection is enabled.
- **User exclusions:** Ignore signed-in visitors or nominated IP addresses when required.
- **Reset actions:** Reset an asset’s count from the control panel when a campaign or reporting period changes.
- **Configurable behaviour:** Manage the counting rules in plugin settings or project configuration.
- **Cleaner download counts:** Exclude known IP addresses, signed-in users, or likely bots when those requests should not affect the total. Counts can appear in the asset index and remain available to Twig for front-end reporting.
